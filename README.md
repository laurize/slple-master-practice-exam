# SLPLE Master Practice Exam — Interactive Website

This repository hosts the static interactive 400-item SLPLE practice exam.

## Publish with GitHub Pages

1. Add the generated `index.html` file from the interactive exam website bundle to the root of this repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/(root)`, then click **Save**.
5. Wait for GitHub Pages to finish publishing. The site URL should be `https://laurize.github.io/slple-master-practice-exam/`.

The exam and its answer key/rationales are public when published.
